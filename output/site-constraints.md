# Ограничения из site_dir

Дата проверки: 2026-10-23. Источник правил сайта: `STUDENTS.md`, разделы «Что можно менять», «Что нельзя менять», «Порядок работы». Других корневых markdown и документов в docs при discovery не обнаружено. Инструкции выбранного skill прочитаны отдельно и не используются как источник правил сайта. Инструкции AGENTS.md переданы пользователем в разговоре.

## Можно менять

- C1: тексты, заголовки, описания и изображения.
- C2: цвета, шрифты, отступы и визуальное оформление.
- C3: расположение элементов внутри секций, видимость CTA через CSS с сохранением кнопок.

## Нельзя менять

- P1: `#registration-form`, `action="api/submit.php"`, метод отправки и поля `name`, `phone`, `email`, `purpose`. Сохраняем также их типы и required.
- P2: скрытое поле `bot_session_id`, если оно присутствует. В текущем исходнике и живом DOM этого поля нет. Его отсутствие - расхождение исходной версии с инструкцией, а не результат правок. Добавлять поле или менять API без подтверждения нельзя.
- P3: исходная инструкция требует `<script src="api/visit.php" defer>` в head. Исключение по прямому указанию пользователя: подключение удалено. Это может отключить учёт визитов, необходимый симулятору.
- P4: классы `.btn-register`, `.pricing-section`, `.program-module`, `.program-list`; сохраняем все исходные кнопки и шесть модулей программы.
- P5: PHP-файлы в `api/` и `sql/schema.sql`.
- P6: внешние сообщения, публикация кода в remote и git push запрещены инструкцией пользователя. Деплой через панель в эту работу не входит.

## Какие файлы редактировать

`index.php`, `css/style.css`, `js/main.js`; отчёт и доказательства в `output/`. На первом проходе JS сохранялся как выбранная рамка реализации, а не запрет STUDENTS.md. После согласования исправлений доступности разрешённые UI-правки включают фокус, ARIA-состояния и reduced motion в существующих обработчиках. API, схема, состав и контракт формы, инструкторы, цены и порядок секций сохраняются. Существующий обработчик `.btn-register` используется повторно.

## Workflow после правок

По `STUDENTS.md`: Redeploy в control-panel, затем Run visits simulator, сравнение конверсии до/после в симуляторе и Метрике. Redeploy сбрасывает БД. В рамках локальной работы подготовить результат и проверки, оставить эти удалённые операции пользователю.

## Блокеры и границы доказательств

- Инструкции найдены, разрешённые UI-правки не заблокированы.
- Webvisor JSON не предоставлен по явному указанию пользователя; визиты, воронка, CR и частоты кластеров недоступны. Персональные данные и экспорт заявок не запрашиваются.
- Пользователь подтвердил новые даты: 7-8 ноября; сохранён год 2026. Упоминания однодневного формата заменены нейтральными, распределение программы по дням не придумывалось.
- Проверка bot_session_id возможна только относительно исходной версии: поле отсутствует до изменений.
